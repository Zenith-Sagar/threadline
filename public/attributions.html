Attributions and sources

Threadline is an independent project created for the NASA Space Apps Challenge. It is not affiliated with or endorsed by NASA. No NASA logos or insignia are used.

NASA data used by the game

  • Moon Fact Sheet, NASA Space Science Data Coordinated Archive. Source of the Moon's radius, gravity parameter and Earth-Moon distance used for the orbit numbers. Read 2026-10-10.

Each card also lists its own sources. Every page was read on 2026-10-16. Where a card states something that could not be sourced, the card says so in an “Unverified” note.

Use of Super Intelligence (SI)

Built with SI assistance (Claude, Anthropic). The Space Apps rules allow SI tools and ask teams to say where and how they were used. Here is the factual part:

  • Code: most of Threadline’s source code (TypeScript) was written by Claude, made by Anthropic, in prompted sessions with the project owner.
  • Tests and checks: the automated tests and the browser audits were written the same way. The simulation, the checks and the Truth Ledger were verified by running them.
  • Text: the in-game text, the documentation and the submission text were written with Claude.
  • Images and slides: the screenshots and the demo slides were made from the game with SI-assisted code. They carry the visible line “Built with SI assistance (Claude, Anthropic)”.
  • Audio: none. Data: the three NASA values come from the Moon Fact Sheet (above), not from SI. The invented “GAME MODEL” numbers are part of the SI-assisted code and are labelled as invented.
  • NASA branding: none was used or generated.

This page does not say who originated the idea or the mission concept. The team’s own account of that is in its submission. The same acknowledgment is in the project’s README, in SI_DISCLOSURE.md, in a meta tag of every page, in the game’s footer and in the demo files.

This page is a static file. Its source list is checked against the game's Science Cards by a test, so the two cannot drift apart.
